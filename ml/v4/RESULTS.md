# v4 고전 머신러닝 모델 비교 결과

실행일: 2026-08-13

## 한눈에 보는 결론

Random Forest, Gradient Boosting, RBF SVM을 모두 시험했지만 **기존 v1.1
로지스틱 회귀보다 일관되게 좋은 모델은 없었다.** 따라서 공개 데이터 기준
모델은 계속 v1.1 로지스틱 회귀를 유지한다.

DTW의 효과는 모델마다 달랐다.

- Random Forest에서는 낙상 F1이 사람·환경 평가에서 모두 조금 올랐다.
- Gradient Boosting과 SVM에서는 사람 평가가 오르면 환경 평가가 내려갔다.
- Random Forest도 점프·스쿼트 낙상 오탐률이 높아졌고 v1.1 성능에는 못 미쳤다.

즉, DTW가 로지스틱 회귀에만 맞지 않았던 것은 아니지만, 다른 모델에서도 현재
공개 데이터의 핵심 문제를 해결하지는 못했다. 자체 이벤트 데이터에서는 다시
검증할 가치가 있으므로 실험 항목으로는 유지한다.

## 실험 구성

- 데이터: ESP-Fi HAR 4개 환경, 8명, 총 2,240개
- 주 평가: `fall`, `walk`, `run`, `turn`, `arm_wave` 1,600개
- 별도 안전성 평가: `jump`, `squat` 640개
- 기존 입력: v1의 45개 통계 특징
- DTW 입력: 학습 fold로만 만든 행동별 대표 파형까지의 거리
- 평가:
  - 처음 보는 사람: 8-fold
  - 처음 보는 환경: 4-fold
- random seed: 42
- 모델 설정은 test 결과를 보고 조정하지 않고 사전에 고정

각 모델은 네 조합으로 평가했다.

| 학습 구성 | 입력 구성 |
|---|---|
| 전체 7개 행동 | 통계 특징만 |
| 전체 7개 행동 | 통계 특징 + DTW |
| 점프·스쿼트 제외 5개 행동 | 통계 특징만 |
| 점프·스쿼트 제외 5개 행동 | 통계 특징 + DTW |

총 3개 모델 × 4개 조합 × 12개 fold로 **144회 학습**했다.

## 모델을 쉽게 설명하면

| 모델 | 판단 방식 |
|---|---|
| Random Forest | 여러 결정 트리가 각각 판단한 뒤 다수결 |
| HistGradientBoosting | 앞 모델이 틀린 사례를 다음 트리가 연속해서 보완 |
| RBF SVM | 특징 공간에서 행동 사이의 휘어진 경계를 찾음 |

## 결과 1: 점프·스쿼트 제외 모델

실제 목표 환경과 가까운 5개 행동 학습 모델의 결과다.

### 처음 보는 사람

| 모델 | 입력 | 전체 균형 점수 | 낙상 적중률 | 낙상 발견률 | 낙상 F1 | 걷기 F1 |
|---|---|---:|---:|---:|---:|---:|
| **v1.1 로지스틱 기준선** | 통계 | **70.44%** | **53.64%** | **55.94%** | **53.04%** | **79.83%** |
| Random Forest | 통계 | 64.30% | 51.59% | 48.13% | 49.13% | 68.71% |
| Random Forest | 통계+DTW | 65.90% | 52.94% | 52.19% | 51.90% | 69.79% |
| Gradient Boosting | 통계 | 66.03% | 50.57% | 53.44% | 51.20% | 71.19% |
| Gradient Boosting | 통계+DTW | 66.74% | 50.88% | 54.06% | 51.74% | 71.88% |
| RBF SVM | 통계 | 66.19% | 48.94% | 54.06% | 50.47% | 73.10% |
| RBF SVM | 통계+DTW | 67.69% | 50.36% | 54.06% | 51.64% | 74.87% |

새 모델 중 가장 높은 낙상 F1은 Random Forest+DTW의 51.90%지만 v1.1보다
1.14%p 낮다. 새 모델들은 특히 걷기 F1이 5~11%p 낮았다.

### 처음 보는 환경

| 모델 | 입력 | 전체 균형 점수 | 낙상 적중률 | 낙상 발견률 | 낙상 F1 | 걷기 F1 |
|---|---|---:|---:|---:|---:|---:|
| **v1.1 로지스틱 기준선** | 통계 | **67.52%** | **52.35%** | **49.69%** | **50.48%** | **74.29%** |
| Random Forest | 통계 | 54.28% | 49.94% | 38.44% | 42.33% | 49.23% |
| Random Forest | 통계+DTW | 55.69% | 51.30% | 38.75% | 42.97% | 51.62% |
| Gradient Boosting | 통계 | 58.80% | 52.19% | 46.56% | 48.18% | 54.72% |
| Gradient Boosting | 통계+DTW | 59.56% | 52.04% | 43.75% | 46.57% | 57.13% |
| RBF SVM | 통계 | 60.22% | 52.28% | 46.88% | 47.37% | 59.33% |
| RBF SVM | 통계+DTW | 60.45% | 52.03% | 46.25% | 46.68% | 60.68% |

새 모델 중 가장 높은 낙상 F1은 Gradient Boosting 통계 모델의 48.18%로,
v1.1보다 2.30%p 낮다. 환경이 바뀌면 새 모델의 걷기 성능도 크게 떨어졌다.

## 결과 2: 전체 7개 행동 모델

점프·스쿼트를 포함해 학습한 결과도 함께 비교했다.

### 처음 보는 사람

| 모델 | 입력 | 전체 균형 점수 | 낙상 F1 | 걷기 F1 |
|---|---|---:|---:|---:|
| **v1.1 로지스틱 기준선** | 통계 | **68.69%** | 46.57% | **78.85%** |
| Random Forest | 통계 | 63.63% | 44.93% | 69.48% |
| Random Forest | 통계+DTW | 65.22% | 48.59% | 69.80% |
| Gradient Boosting | 통계 | 65.76% | 45.81% | 73.24% |
| Gradient Boosting | 통계+DTW | 65.22% | 45.75% | 71.62% |
| RBF SVM | 통계 | 65.40% | 45.14% | 74.24% |
| RBF SVM | 통계+DTW | 68.27% | **49.29%** | 76.27% |

RBF SVM+DTW가 낙상 F1은 가장 높았지만 걷기와 전체 균형 점수는 기준선보다
낮았다. 환경 평가에서도 같은 개선이 반복되지 않았다.

### 처음 보는 환경

| 모델 | 입력 | 전체 균형 점수 | 낙상 F1 | 걷기 F1 |
|---|---|---:|---:|---:|
| **v1.1 로지스틱 기준선** | 통계 | **64.62%** | 41.21% | **73.76%** |
| Random Forest | 통계 | 55.23% | 42.63% | 49.89% |
| Random Forest | 통계+DTW | 56.97% | 41.76% | 54.80% |
| Gradient Boosting | 통계 | 57.67% | 41.61% | 55.72% |
| Gradient Boosting | 통계+DTW | 59.45% | 41.76% | 59.18% |
| RBF SVM | 통계 | 60.73% | **46.16%** | 60.07% |
| RBF SVM | 통계+DTW | 60.56% | 44.80% | 61.26% |

환경 평가에서는 RBF SVM 통계 모델이 낙상 F1은 높였지만 걷기 F1이
13.69%p 낮아졌다. 낙상 하나만 개선하고 다른 핵심 행동을 크게 희생하므로
채택하지 않는다.

## DTW 효과 비교

점프·스쿼트 제외 모델에서 통계 특징에 DTW를 추가했을 때의 낙상 F1 변화다.

| 모델 | 처음 보는 사람 | 처음 보는 환경 | 판단 |
|---|---:|---:|---|
| Random Forest | +2.77%p | +0.64%p | 양쪽 개선, 하지만 기준선 미달 |
| Gradient Boosting | +0.54%p | -1.61%p | 일관되지 않음 |
| RBF SVM | +1.17%p | -0.69%p | 일관되지 않음 |

DTW가 Random Forest에는 일부 도움이 됐으므로 모델마다 검증하자는 원칙은
타당했다. 그러나 Random Forest+DTW도 v1.1보다 낮고 제외 행동 오탐이 증가했다.

## 점프·스쿼트 안전성

점프·스쿼트를 제외하고 학습한 모델에 두 행동을 별도로 입력한 낙상 오인율이다.

| 모델 | 입력 | 처음 보는 사람 | 처음 보는 환경 |
|---|---|---:|---:|
| v1.1 로지스틱 | 통계 | 32.66% | 31.56% |
| Random Forest | 통계 | **25.78%** | **20.00%** |
| Random Forest | 통계+DTW | 28.91% | 22.19% |
| Gradient Boosting | 통계 | 30.31% | 25.47% |
| Gradient Boosting | 통계+DTW | 31.41% | 28.12% |
| RBF SVM | 통계 | 31.88% | 27.19% |
| RBF SVM | 통계+DTW | 31.25% | 27.03% |

Random Forest의 오탐률은 낮지만 실제 낙상 발견률과 걷기 성능도 함께 낮다.
경보를 적게 내서 생긴 안전해 보이는 결과일 수 있으므로 이것만으로 채택하지 않는다.

## 최종 판단

- **기준선 유지:** v1.1 점프·스쿼트 제외 로지스틱 회귀
- **Random Forest 미채택:** DTW 효과는 있었지만 기준선보다 낮음
- **Gradient Boosting 미채택:** 환경·걷기 일반화가 기준선보다 낮음
- **RBF SVM 미채택:** 일부 낙상 F1은 높지만 걷기 희생과 평가 간 불일치가 큼
- **DTW 비교 유지:** 새 모델과 자체 데이터에서도 짝지어 검증

이 결과는 고정된 합리적 기본 설정 비교이며 각 모델의 가능한 모든 설정을
탐색한 성능 상한은 아니다. 그러나 test fold를 보며 설정을 고르는 과적합을
피했고, 현재 단계에서 복잡한 튜닝보다 자체 ESP32-S3 데이터 검증이 우선이다.
