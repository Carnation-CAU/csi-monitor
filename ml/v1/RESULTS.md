# v1 머신러닝 실험 결과

실행일: 2026-08-12

## 한눈에 보는 결론

**현재 모델은 걷기는 어느 정도 구분하지만, 낙상 의심 판단은 많이 틀린다.**
따라서 아직 실제 서비스에 사용할 수 없다.

- 처음 보는 사람의 걷기 점수: **78.74점**
- 처음 보는 사람의 낙상 점수: **38.77점**
- 처음 보는 장소의 낙상 점수: **34.23점**
- 낙상 뒤 움직이지 않는 조건을 추가해도 결과가 거의 좋아지지 않음

이번 실험의 의미는 실패 원인을 찾았다는 데 있다. 지금은 모델을 복잡하게
만드는 것보다 우리 장비로 실제 사용 환경의 데이터를 모으는 일이 더 중요하다.

## 결과 숫자를 읽는 방법

아래 용어만 알면 나머지 결과를 읽을 수 있다.

| 용어 | 쉬운 뜻 | 예시 |
|---|---|---|
| 정확도(Accuracy) | 전체 예측 중 맞힌 비율 | 100개 중 75개를 맞히면 75% |
| 경보 적중률(Precision) | 낙상이라고 알린 것 중 실제 낙상 비율 | 경보 100번 중 실제 낙상이 38번이면 38% |
| 낙상 발견률(Recall) | 실제 낙상 중 모델이 찾아낸 비율 | 실제 낙상 100번 중 41번 찾으면 41% |
| F1 | 적중률과 발견률을 함께 반영한 점수 | 100점에 가까울수록 좋음 |
| 전체 균형 점수(Macro-F1) | 각 행동을 동일한 중요도로 계산한 평균 점수 | 데이터 개수 차이의 영향을 줄임 |

이 데이터는 `기타 움직임`이 전체의 71.43%다. 따라서 아무것도 배우지 않고
항상 `기타 움직임`이라고 답해도 정확도는 71.43%가 나온다. 그래서 이 실험에서는
전체 정확도보다 **낙상 적중률, 낙상 발견률, 낙상 F1**을 더 중요하게 본다.

## 이번에 한 일

모든 과정은 딥러닝 없이 비교적 단순한 머신러닝인 로지스틱 회귀를 사용했다.
로지스틱 회귀는 여러 신호 특징을 보고 각 행동일 가능성을 계산하는 분류
방법이다.

1. 공개 데이터의 4개 장소 데이터를 모두 확보했다.
2. 원래 7개 행동을 학습한 뒤 최종 결과만 3개로 합쳤다.
3. 낙상을 먼저 판단하고, 낙상이 아니면 걷기와 기타 움직임을 구분해 봤다.
4. 낙상 점수에 `움직인 뒤 가만히 있었는가`라는 조건도 합쳐 봤다.

최종 출력은 다음 3개다.

```text
walking          걷기
fall_suspected   낙상 의심
other_motion     그 밖의 움직임
```

## 사용한 공개 데이터

ESP-Fi HAR 전체 데이터는 다음과 같이 구성돼 있다.

- 장소 4개: 복도, 사무실, 회의실, 실험실
- 참가자 8명
- 행동 7개: 걷기, 달리기, 점프, 스쿼트, 팔 흔들기, 방향 전환, 낙상
- 같은 행동을 사람과 장소별로 10번 반복
- 총 2,240개 데이터
- 데이터 하나는 약 10초
- 초당 약 100번 신호 측정
- 한 번 측정할 때 52개 Wi-Fi CSI 진폭값 사용

### 행동 번호 오류 확인

공식 설명에 적힌 행동 번호와 실제 압축파일의 행동 번호가 일부 달랐다. 기존
benchmark 파일과 전체 데이터의 신호가 완전히 같은지 직접 비교해 아래 번호를
확정했다.

| 번호 | 실제 행동 |
|---:|---|
| 1 | 달리기 |
| 2 | 걷기 |
| 3 | 점프 |
| 4 | 스쿼트 |
| 5 | 팔 흔들기 |
| 6 | 방향 전환 |
| 7 | 낙상 |

이 검증을 하지 않았다면 여러 행동에 잘못된 정답표를 붙여 학습할 수 있었다.

### 중복 패킷 문제

일부 원본 CSV에는 같은 신호가 여러 번 반복 저장돼 있었다.

- 확인한 중복 패킷: 22,548개
- 전체 2,240개 중 무활동 분석에 충분한 데이터: 1,778개(79.4%)
- 특히 사무실 데이터에서 중복 문제가 많았음

중복 신호는 제거했다. 제거 후 고유 신호가 부족한 데이터에는 무활동 조건을
적용하지 않았다.

## 비교한 세 가지 방법

### 방법 A: 7개 행동을 배운 뒤 3개로 합치기

모델은 걷기, 낙상, 점프 등 7개 행동의 차이를 모두 학습한다. 예측이 끝난 뒤
다음처럼 결과를 합친다.

```text
낙상 -> 낙상 의심
걷기 -> 걷기
나머지 5개 행동 -> 기타 움직임
```

이 방법이 이번 실험에서 가장 안정적이었다.

### 방법 B: 두 단계로 나눠 판단하기

```text
1단계: 낙상인가?
2단계: 낙상이 아니라면 걷기인가, 기타 움직임인가?
```

낙상을 더 많이 찾을 수 있었지만 정상 행동도 낙상이라고 판단하는 경우가 크게
늘었다.

### 방법 C: 낙상 점수와 무활동 합치기

방법 B에 다음 조건을 추가했다.

```text
낙상 가능성이 높음
그리고
큰 움직임 뒤 일정 시간 조용함
-> 낙상 의심
```

무활동 기준과 낙상 가능성 기준은 시험 데이터를 보지 않고 학습 데이터 안에서만
선택했다.

## 결과 1: 처음 보는 사람

참가자 한 명의 데이터를 전부 빼고 나머지 7명으로 학습한 뒤, 빼둔 사람을
시험했다. 이를 8명 모두에게 반복했다.

| 방법 | 전체 정확도 | 전체 균형 점수 | 낙상 경보 적중률 | 낙상 발견률 | 낙상 종합 점수 | 걷기 종합 점수 |
|---|---:|---:|---:|---:|---:|---:|
| **A. 7개 행동 후 합치기** | **76.92%** | **67.28%** | **38.14%** | 40.62% | **38.77%** | **78.74%** |
| B. 두 단계 판단 | 52.86% | 54.23% | 23.35% | 74.06% | 35.20% | 70.94% |
| B. 낙상 기준 자동 조정 | 50.80% | 52.79% | 22.93% | **76.88%** | 35.01% | 69.81% |
| C. 두 단계 + 무활동 | 54.15% | 54.01% | 23.46% | 73.44% | 35.27% | 68.94% |

방법 A를 쉽게 해석하면 다음과 같다.

- 낙상 경보 100번 중 실제 낙상은 약 38번
- 실제 낙상 100번 중 약 41번만 발견
- 걷기는 약 79점으로 어느 정도 구분

방법 B는 실제 낙상 100번 중 약 74번을 찾지만, 낙상 경보 100번 중 실제 낙상은
약 23번뿐이다. 낙상을 더 많이 찾는 대신 거짓 경보가 지나치게 많아진 것이다.

## 결과 2: 처음 보는 장소

장소 하나를 전부 빼고 나머지 3개 장소로 학습한 뒤, 빼둔 장소를 시험했다.
이를 4개 장소 모두에 반복했다.

| 방법 | 전체 정확도 | 전체 균형 점수 | 낙상 경보 적중률 | 낙상 발견률 | 낙상 종합 점수 | 걷기 종합 점수 |
|---|---:|---:|---:|---:|---:|---:|
| **A. 7개 행동 후 합치기** | **74.87%** | **63.58%** | **34.99%** | 33.75% | 34.23% | **73.38%** |
| B. 두 단계 판단 | 55.00% | 54.62% | 24.20% | 70.00% | 35.68% | 67.66% |
| B. 낙상 기준 자동 조정 | 53.12% | 53.64% | 23.34% | **71.88%** | 35.06% | 67.60% |
| C. 두 단계 + 무활동 | 57.90% | 55.93% | 25.06% | 69.69% | **36.77%** | 67.69% |

장소가 바뀌면 방법 A의 낙상 종합 점수가 38.77점에서 34.23점으로 내려간다.
즉, Wi-Fi CSI 신호가 방 구조와 기기 배치의 영향을 많이 받는다는 뜻이다.

## 무활동 조건이 별로 도움이 되지 않은 이유

우리는 낙상 후 사람이 가만히 있을 것이라고 예상했다. 하지만 공개 데이터는
각 행동을 한 번 수행하고 녹화를 끝내는 방식이다. 걷기나 달리기를 한 사람도
행동을 마치면 멈춘다.

실제로 행동이 끝난 뒤 조용한 정도의 대표값은 다음과 같았다. 1에 가까울수록
조용한 구간이 많다는 뜻이다.

| 행동 | 분석 가능한 데이터 수 | 조용한 정도 |
|---|---:|---:|
| 낙상 | 262 | 0.694 |
| 점프 | 252 | 0.701 |
| 스쿼트 | 265 | 0.727 |
| 팔 흔들기 | 257 | 0.744 |
| 방향 전환 | 243 | 0.663 |
| 걷기 | 236 | 1.000 |
| 달리기 | 263 | 1.000 |

오히려 걷기와 달리기도 마지막 구간에서는 매우 조용했다. 따라서 이 공개
데이터에서 `움직인 뒤 정지`는 낙상만의 특징이 아니다.

실제 생활을 계속 녹화한 데이터라면 `낙상으로 보이는 큰 변화 뒤 장시간 움직임이
없음`이 유용할 수 있다. 하지만 현재처럼 행동 하나씩 10초간 녹화한 데이터로는
그 가능성을 제대로 검증할 수 없다.

## 최종 판단

| 확인한 내용 | 판단 |
|---|---|
| 전체 4개 장소 데이터 확보 | 완료 |
| 7개 행동을 이용한 학습 | 현재 방법 중 가장 안정적 |
| 두 단계 분류 | 낙상은 많이 찾지만 거짓 경보가 너무 많음 |
| 무활동 조건 | 공개 데이터에서는 효과가 거의 없음 |
| 실제 서비스 적용 | 불가능 |

다음 단계는 바로 딥러닝으로 넘어가는 것이 아니다. 우리 ESP32-S3 장비로 실제
사용 조건에 가까운 연속 데이터를 모아야 한다.

- 걷기
- 빠르게 앉기
- 침대나 바닥에 눕기
- 주저앉기
- 안전한 모의 낙상
- 각 행동 뒤 다시 움직이는 경우와 오랫동안 움직이지 않는 경우

이런 데이터가 있어야 `행동 후 무활동`이 실제 낙상 판단에 도움이 되는지 제대로
확인할 수 있다.

