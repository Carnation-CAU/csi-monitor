# 움직임 데이터 수집 계획

최종 갱신일: 2026-08-04

## 목적

현재 배치에서 움직임·정지 판정이 반복해서 재현되는지 확인하고, 이후
낙상 후보 규칙과 분류 모델에 사용할 기준 데이터를 만든다.

## 한 세트 안에서 고정할 조건

아래 값은 수집을 시작하기 전에 정하고, 한 세트를 수집하는 동안 바꾸지 않는다.
실제 값은 환경마다 다르므로 사용 중인 공간 프로필에 기록된 값을 따른다.

- 장소: 감지 대상 구역 (예: 침대나 소파 주변)
- 배치: TX/RX를 대상 구역을 사이에 둔 대각선, 거리 기록
- 채널: 자동 비교에서 선택된 채널
- 채널 폭: HT40
- TX 송신 설정: 100Hz
- RX: COM8 UART, 2,000,000 baud
- 빈 공간 보정: 완료

보드 전원, 위치, 높이, 안테나 방향 또는 채널이 바뀌면 새 실험 묶음으로
분리하고 빈 공간 보정을 다시 실행한다.

## 1차 예비 수집

각 행동을 30초씩 한 번 수집해 파일과 라벨 흐름부터 검증한다.

1. 빈 공간
2. 사람이 서서 정지
3. 천천히 걷기
4. 침대에 천천히 눕기
5. 누워서 정지
6. 누운 상태에서 몸 돌리기
7. 침대에서 일어나기

현재 진행 상태:

- `empty_room`: Radar 표본 120개 중 움직임 0회
- `standing_static`: 유효 회차 Radar 표본 106개 중 움직임 9회. 약 2초에 집중된 정지 오탐 사례
- 첫 `standing_static` 회차는 사용자가 완료 전에 이동해 무효 처리
- `walking_slow`: Radar 표본 120개 중 움직임 96회, 판정 비율 80.0%
- `lying_static`: Radar 표본 121개 모두 정지 판정, 움직임 오탐 0회
- `turn_in_bed`: Radar 표본 120개 중 움직임 61회, 판정 비율 50.8%
- `lie_down_slow`: 움직임 판정 10회가 기록 시작 0.0~2.5초에 집중, 전환 포착
- `get_up_from_bed`: 움직임 판정 19회가 기록 13.1~18.1초에 집중, 중앙 전환 포착

1차 예비 수집의 일곱 라벨이 모두 완료됐다. 시간 신호, 행동 시작 시각,
유효성 확인, 공간 프로필 연결과 한글 요약을 자동화한 GUI 수집 기능도
구현했다.

## 2차 반복 수집

예비 수집 파일이 정상인 것을 확인한 뒤 정지·연속 행동은 60초씩 5회
수집한다. 눕기·일어나기처럼 시작과 끝이 있는 행동은 20초씩 10회 수집하고
10초 시점의 GUI 행동 신호에 맞춰 한 번 수행한다. 모델 평가 때 같은 세션의
일부가 학습과 시험에 동시에 들어가지 않도록 세션 단위로 분리한다.

진행 순서는 `empty_room`부터 표의 라벨 순서대로 하며, 한 라벨의 전체 회차를
끝낸 뒤 다음 라벨로 넘어간다. 각 회차 종료 후 GUI에서 유효 여부를 확인한다.
첫 시작은 `empty_room`, 60초, 5회이며 중간 행동 신호는 사용하지 않는다.

## 권장 라벨

| 행동 | 라벨 |
|---|---|
| 빈 공간 | `empty_room` |
| 서서 정지 | `standing_static` |
| 걷기 | `walking_slow` |
| 천천히 눕기 | `lie_down_slow` |
| 누워서 정지 | `lying_static` |
| 누워서 몸 돌리기 | `turn_in_bed` |
| 침대에서 일어나기 | `get_up_from_bed` |
| 빠르게 앉기 | `sit_down_fast` |
| 물건 줍기 | `pick_up_object` |
| 매트리스 위 통제된 모의 낙상 | `fall_simulated_mattress` |

`sit_down_fast`와 `pick_up_object`는 낙상과 신호가 비슷할 수 있는 비교 행동이다.
이를 제외하면 낙상처럼 큰 변화가 생기는 정상 행동을 모델이 모두 낙상으로
오인할 수 있다.

## 기록할 환경 정보

- 측정 날짜와 시간
- 행동과 회차
- 실제 행동 시작·종료 시각
- TX/RX 거리·높이·방향
- 문과 창문 상태
- 주변에서 움직인 다른 사람 여부
- 링크 중단 또는 예상 밖 판정

## 예비 수집 완료 기준

- 일곱 라벨의 원본 JSONL과 세션 정보 파일 생성
- 각 파일에 Radar 및 링크 로그 포함
- 파일별 라벨과 실제 행동 일치
- 10초 이상 링크 중단 없음
- 다음 날 같은 배치에서 정지·움직임 전환 재현

## 안전

실제 바닥 낙상은 수행하지 않는다. `fall_simulated_mattress`는 충격을 충분히
흡수하는 매트리스와 옆에서 도와줄 성인이 준비된 상태에서 통제된 동작만
수행한다. GUI의 안전 확인에 동의하지 않으면 수집을 시작하지 않는다.
통증, 어지럼증 또는 신체적 위험이 있으면 이 라벨은 수집하지 않는다.

매트리스 모의 낙상 데이터는 해당 조건의 실험 데이터일 뿐 실제 단단한 바닥
낙상 성능을 증명하지 않는다.

## 행동 인식 진행 조건

다음 조건을 충족한 뒤 첫 분류기를 만든다.

- 모든 라벨에서 계획한 유효 회차 확보
- 각 manifest에 같은 공간 프로필과 채널 기록
- 전환 행동에 `eventAtUtc` 기록
- 10초 이상 링크 중단 회차 제외 또는 무효 표시
- 학습·검증 데이터를 원본 세션 단위로 분리

첫 모델은 Radar 시계열의 wander, jitter, 움직임 비율, 최대 변화량, 변화 후
정지 구간과 RSSI를 사용하는 기준 모델로 만든다. 결과는 현재 사람·현재 방
전용 실험 성능으로 표시하고 다른 환경 일반화 성능과 구분한다.

## 즉시 행동 유사도 시험 현황

- `walking_slow` 30초 시험: 실제 `walking_slow`, 예측 `walking_slow`, 분리도 30.9%
- `lying_static` 30초 시험: 실제 `lying_static`, 예측 `lying_static`, 분리도 81.1%
- `fall_simulated_mattress` 두 번째 시험: 실제 모의 낙상, 예측 `get_up_from_bed`, 분리도 약 14%

첫 기능 시험은 일치했지만 한 회차 결과이므로 정확도로 계산하지 않는다.
두 모의 낙상 회차의 신호 크기가 크게 달라 현재 최근접 방식에서는 낙상을
안정적으로 구분하지 못했다. 추가 낙상 동작을 반복하기보다 행동 신호 주변의
짧은 구간을 분석하는 이벤트 중심 특징을 먼저 검토한다.
