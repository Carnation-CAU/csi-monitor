# ESP32-S3 Wi-Fi CSI 문서 안내

기존 통합 문서는 환경과 사용법을 독립적으로 관리하기 위해 다음 두 문서로 분리되었다.

- [개발 환경](environment.md): 버전, 경로, 하드웨어, 아키텍처와 검증 상태
- [macOS 사용법](usage-macos.md): Mac 연결, 실행, 플래시와 빈방 수집 명령
- [Windows 사용법](usage-windows.md): PowerShell 연결, 실행, 플래시와 빈방 수집 명령
- [공통 사용법](usage.md): 화면 해석, 공간 보정, 프로필과 수집 규칙
- [채널 보정](channel-calibration.md): 설치 채널 선택 순서, 평가 기준과 현재 자동화 범위
- [성장 및 추가 개발 로드맵](growth-roadmap.md): 다음 개발 단계와 단기·중기 개선점

이 파일은 기존 링크가 깨지지 않도록 안내용으로 유지한다. 최신 내용은 위 문서를 기준으로 한다.
