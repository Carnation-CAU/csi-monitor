# 성장 및 추가 개발 로드맵

최종 갱신일: 2026-08-04

## 현재 완료 범위

- ESP32-S3 두 대의 ESP-NOW 송수신과 CSI 수집
- Espressif 공식 Radar 기반 움직임·정지 판정
- 실시간 GUI의 움직임 신호, 임계값, RSSI, 패킷률 표시
- 빈 공간 보정
- 채널 1·6·11 동기 전환과 자동 비교
- 실사용 배치에서 기본 행동 확인
- 자동 선택된 채널에서 빈 공간 보정 및 정지·걷기·눕기 반응 확인
- Windows 개발 환경과 향후 macOS 이식 구조

## 바로 진행할 핵심 단계

### 1. 고정 배치 움직임 데이터셋

- 빈 공간
- 사람 정지
- 걷기
- 눕기
- 누운 뒤 정지
- 몸 돌리기
- 일어나기

각 상태를 여러 회차로 수집하고 실제 행동 시작·종료 시각을 기록한다.
구체적인 첫 수집 순서는 [움직임 데이터 수집 계획](movement-data-collection-plan.md)을 따른다.

2026-08-04에 일곱 라벨의 30초 1차 예비 수집을 완료했다. 다음은 수집
보조 기능을 정리한 뒤 60초 3회 반복 데이터셋으로 확장하는 단계다.

### 2. 움직임 감지 성능표

- 실제 움직임을 움직임으로 잡은 비율
- 실제 정지를 정지로 잡은 비율
- 감지 지연 시간
- `WAITING` 또는 링크 중단 횟수
- 시간대와 가구·문 상태 변화에 따른 차이

현재의 성공 사례를 정량적인 재현성 결과로 바꾸는 단계다.

### 3. 낙상 후보 규칙

급격한 CSI 변화 뒤 정지가 이어지는 구간을 낙상 후보로 분리한다. 실제
사람이 바닥으로 넘어지는 시험은 하지 않고 안전 매트와 통제된 낮은 높이의
모의 행동만 사용한다. 앉기·눕기·물건 줍기를 오탐 비교 행동으로 포함한다.

### 4. 서버와 안드로이드 알림

낙상 의심 또는 장기 무활동 이벤트를 서버에 저장하고 FCM으로 보호자 앱에
전송한다. 알림은 낙상을 확정하지 않고 확인 요청으로 표현한다.

## 채널 보정 개선점

### 단기 개선

- 채널당 측정 시간을 30~60초로 확대
- 2~3회 반복 측정
- 순간 최저값 대신 하위 10% 패킷률 사용
- 결과를 JSON 또는 Markdown으로 자동 저장
- 이전 측정과 현재 측정 비교 화면

### 중기 개선

- 1·6·11 1차 탐색 후 우승 채널 주변의 2차 정밀 탐색
- 한국 국가 코드와 허용 채널을 명시적으로 설정하고 규정 검증
- 선택 채널 NVS 저장
- TX 전환 확인 응답과 실패 시 채널 6 자동 복귀
- 배치별 채널·Radar 보정값을 설치 프로필로 관리

## 환경 변화 대응

- TX/RX 위치·높이·방향 변경 시 재측정
- 문·대형 가구·금속 물체 변경 시 재측정
- 다른 집으로 이동하면 채널 비교와 빈 공간 보정을 처음부터 수행
- 낮·밤과 공유기 사용량이 다른 시간대에 반복 확인
- 여러 방을 다루려면 링크 또는 RX를 추가해 방별 신호를 분리

## 서비스 확장 순서

1. 움직임·정지 신뢰도 확보
2. 장기 무활동 규칙
3. 낙상 후보 탐지와 보호자 확인
4. 일일 활동 요약
5. 외출·귀가 판단
6. 외부 침입 의심 감지
7. 개인별 생활 패턴 학습
8. 랜딩 페이지와 신청 흐름

외부 침입 기능은 등록 스마트폰의 집 Wi-Fi 연결, Bluetooth 근접, GPS와
CSI 움직임을 조합한다. CSI만으로 집주인과 침입자를 구분하지 않는다.

## 제품화 전 필수 항목

- 자동 재연결과 장애 복구
- 보정값과 설치 프로필 영구 저장
- 센서 온라인·오프라인 상태 확인
- 펌웨어 업데이트 절차
- 개인정보 처리와 데이터 보관 정책
- 장기간 실제 환경 시험
- 낙상 확정이 아닌 위험 상황 선별이라는 표현 유지
