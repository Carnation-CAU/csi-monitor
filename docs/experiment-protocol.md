# 기본 실험 규약

## 배치

- 송수신기 거리: 최초 3 m
- 높이: 1 m
- 안테나 방향: 서로 평행
- 금속 표면과 노트북 뒤를 피함
- 2.4 GHz 채널 고정
- 배치 사진과 채널을 세션 manifest에 기록

## 최초 수집

각 상태를 2분씩 독립 세션으로 수집한다.

1. 빈 방: `empty_room`
2. 사람 정지: `person_static`
3. 천천히 걷기: `walking_slow`
4. 빠르게 걷기: `walking_fast`
5. 앉기/일어나기: `sit_stand`

이후 10분 연속 수집으로 안정성을 확인한다.

## 완료 기준

- 비정상 종료 없이 10분 저장
- 모든 원본 레코드에 UTC 시각, 세션, 장치, 라벨 포함
- 세션 manifest 생성
- 빈 방과 움직임의 차이를 파형 및 기초 통계로 확인
- 실제 샘플 수와 누락률 기록

## 안전

실제 바닥 낙상은 수행하지 않는다. `fall_simulated_mattress`는 충격을 충분히
흡수하는 침대·매트리스와 보조 인력이 준비된 경우에만 건강한 성인이 통제된
동작으로 수행하며, 고령자는 참여시키지 않는다.
