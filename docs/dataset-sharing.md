# 팀 CSI 데이터셋 공유와 재사용

최종 확인일: 2026-08-11

## 목적

같은 프로젝트 형식으로 수집한 ESP32-S3 ESP-Radar 행동 데이터를 팀원끼리
공유하고, 원본 출처를 유지한 채 다른 공간 프로필의 참고 행동 데이터로
사용한다.

다른 공간의 공식 빈방 보정값은 가져오지 않는다. 공유 데이터는 행동 유사도와
후속 모델 학습에만 사용하며, 대상 공간의 채널 선택과 빈방 보정은 현장에서
별도로 수행한다.

## 현재 지원 범위

지원:

- 프로젝트 GUI로 수집한 유효한 `esp-radar-jsonl` 행동 세션
- 기본 목록 또는 GUI의 `행동 추가`로 등록한 안전한 행동 라벨
- 체크섬이 일치하는 `.csi-dataset.zip` 팀 번들
- 한 프로필에 여러 참조 데이터셋 연결
- 참조 데이터셋 연결 해제
- 공식 임계값 대비 상대 `wander/jitter` 특징 생성

아직 미지원:

- Intel 5300, Widar, WiAR 등 다른 CSI 형식 자동 변환
- 임의 CSV 열 자동 매핑
- 가져온 데이터셋 파일 삭제 GUI
- 참여자·공간 단위 학습/검증 분리 자동화
- 일반화 모델 학습과 정확도 보고

## 개인정보와 원본 보존

공유 번들의 `dataset.json`에는 공간 프로필의 MAC 주소, TX/RX 위치와 상세
배치 설명을 넣지 않는다. 다만 원본 직렬 로그는 수정하지 않으므로 보드를
재시작하며 수집했다면 부팅 로그에 장치 MAC이 들어 있을 수 있다. 팀 외부 공개
전에는 원본 로그를 별도로 검사한다. 다음 출처 정보는 유지한다.

- 원본 프로필 ID와 표시 이름
- 채널, 대역폭과 송신률
- 세션 ID와 행동 라벨
- 원본 JSONL과 세션 manifest
- 파일별 SHA-256 체크섬
- 전처리 버전

가져온 파일은 `data/datasets/<dataset-id>`에 별도로 저장한다. 기존
`data/raw`, `data/manifests`와 원본 프로필은 수정하지 않는다.

## GUI 사용 순서

### 내 데이터 내보내기

1. 수집 데이터가 연결된 공간 프로필을 선택한다.
2. `현재 프로필 데이터 내보내기`를 누른다.
3. `.csi-dataset.zip` 파일의 저장 위치를 선택한다.
4. 완료된 ZIP 파일만 팀원에게 전달한다.

무효 세션, 알 수 없는 라벨과 원본 파일이 없는 세션은 내보내지 않는다.

### 동료 데이터 가져오기

1. `데이터셋 번들 가져오기`를 누른다.
2. 동료에게 받은 `.csi-dataset.zip`을 선택한다.
3. 체크섬과 JSONL 검사가 끝났는지 완료창을 확인한다.
4. `참조 데이터셋` 목록에서 가져온 데이터셋을 선택한다.
5. `선택 데이터 연결`을 눌러 현재 공간 프로필에 연결한다.

잘못 연결했다면 같은 데이터셋을 선택하고 `선택 데이터 연결 해제`를 누른다.
연결 해제는 라이브러리 원본 파일을 삭제하지 않는다.

## 명령줄 사용

```powershell
python -m csi_gateway dataset-export `
  --profile-id <프로필-ID> `
  --output .\data\exports\team-data.csi-dataset.zip

python -m csi_gateway dataset-import `
  --bundle .\team-data.csi-dataset.zip

python -m csi_gateway dataset-list

python -m csi_gateway dataset-attach `
  --profile-id <대상-프로필-ID> `
  --dataset-id <데이터셋-ID>

python -m csi_gateway dataset-detach `
  --profile-id <대상-프로필-ID> `
  --dataset-id <데이터셋-ID>
```

프로젝트 밖에서 실행하면 모든 명령에 `--project-root`를 지정한다.

## 공간 간 상대 특징

공간마다 신호 절대 크기가 다르므로 참고 행동 비교에는 다음 상대 특징을
사용한다.

```text
wander 상대값 = wander / 해당 표본의 someone threshold
jitter 상대값 = jitter / 해당 표본의 move threshold
```

평균, 표준편차, 최대값과 전반부·후반부 상대 jitter를 계산하고, 움직임·사람
판정 비율을 함께 사용한다. 임계값이 0인 손상·초기 표본은 상대값 0으로 처리한다.

상대 특징도 완전한 환경 일반화를 보장하지 않는다. 새 공간에서는 최소한
빈방, 정지와 대표 움직임 기준을 직접 수집하고 공식 빈방 보정을 완료해야 한다.

## 데이터 누출 방지

하나의 세션을 잘라 학습과 시험 양쪽에 넣지 않는다. 모델 평가를 시작할 때는
다음 단위 전체를 한쪽에만 배정한다.

- 세션
- 사람
- 공간 프로필
- 외부 데이터셋

참조 데이터를 연결했다는 사실은 정확도 향상을 의미하지 않는다. 다른 사람과
다른 공간 데이터가 실제 대상 공간에서 도움이 되는지는 별도 홀드아웃 시험으로
확인한다.
