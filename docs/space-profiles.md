# 공간 프로필 운영 원칙

최종 확인일: 2026-08-11

Wi-Fi CSI 데이터는 행동만으로 결정되지 않고 방 구조, TX/RX 배치, 채널,
안테나 방향, 사람 위치와 가구 상태의 영향을 함께 받는다. 따라서 모든
수집 세션은 하나의 공간 프로필에 연결한다.

## 기본 프로필

프로필이 하나도 없으면 GUI가 빈 기본 프로필을 만든다.

- ID: `default-space`
- 표시 이름: `기본 공간`
- 배치·거리·보정값·장치 MAC: 비어 있음
- 초기 채널: 6, HT40

값이 비어 있는 것이 정상이다. 실제 배치를 입력하고 `채널 + 공간 통합 보정`을
한 번 수행하면 그때부터 채널과 임계값이 이 프로필에 함께 저장된다.

수집 데이터와 공간 프로필은 개인 환경 정보(방 배치, 보드 MAC, 생활 패턴)를
담으므로 저장소에 올리지 않는다. 각자 자신의 PC에서 만들어 사용한다.

## GUI에서 여러 프로필 사용

- 드롭다운에서 현재 작업할 공간 프로필을 선택한다.
- `새 프로필 추가`에서 이름, 배치 설명과 TX-RX 거리를 입력한다.
- `선택 프로필 수정`에서 이름, 배치 설명, 거리와 TX/RX 위치·높이를 갱신한다.
- `선택 프로필 삭제`는 프로필을 복구용 보관 폴더로 이동한다.
- 프로필 선택만으로 보드 설정은 변하지 않는다.
- `공간 프로필 적용`을 눌러야 저장 채널과 보정값이 보드에 적용된다.
- 선택한 상태에서 통합 보정을 하면 채널 비교 성공 후 기존 보정값을 무효화하고,
  선택 채널의 새 빈 공간 임계값으로 즉시 교체한다.
- 선택한 상태에서 행동 데이터를 수집하면 세션이 그 프로필에 연결된다.
- 가져온 팀 데이터셋은 `선택 데이터 연결`로 참고 데이터에 추가하고
  `선택 데이터 연결 해제`로 분리한다.

이름만 수정하면 기존 보정값을 유지한다. 거리, 배치 설명, TX 위치 또는 RX
위치를 수정하면 물리적 전파 환경이 달라진 것으로 간주하여 저장된 보정값을
자동으로 무효화한다. 수정 후 최종 배치에서 빈 공간 보정을 다시 실행한다.

프로필은 `data/profiles`에 하나의 JSON 파일씩 저장된다. 저장소에는 올라가지
않지만, 프로젝트 폴더를 통째로 옮기면 Windows에서 만든 프로필과 데이터를
macOS에서도 그대로 쓸 수 있다.

삭제한 프로필은 `data/profiles/archive`에 남는다. 연결된 행동 원본,
manifest와 분석 결과는 삭제하지 않는다. 최소 하나의 활성 프로필은 항상
유지한다.

## 같은 프로필로 계속 수집할 조건

- 같은 방과 같은 감지 구역
- TX/RX의 역할, 위치와 높이가 동일
- 안테나 방향이 가능한 한 동일
- 큰 가구와 문 상태가 실험 기준에서 크게 달라지지 않음

하나라도 크게 바뀌면 새 공간 프로필을 만들거나 기존 프로필에서 다시 빈
공간 보정을 해야 한다. 다른 배치의 데이터를 같은 프로필에 섞지 않는다.

## 복원 가능한 것과 불가능한 것

프로필로 복원 가능한 값:

- Wi-Fi 채널
- 존재·움직임 보정 임계값
- 민감도, 버퍼 크기와 이상치 개수
- 사용 장치와 관련 세션 정보

사람이 직접 복원해야 하는 조건:

- TX/RX 실제 위치와 거리
- 높이와 안테나 방향
- 전원 상태
- 주요 가구와 문 상태

프로필 적용 후에는 반드시 정지 30초와 실제 움직임으로 정상 여부를 확인한다.

참조 데이터셋 연결은 채널, 공식 Radar 임계값과 `needsCalibration`을 바꾸지
않는다. 다른 공간의 행동 특징을 참고하는 관계일 뿐이며, 대상 공간의 빈방
보정을 대신하지 않는다. 자세한 내용은 [팀 데이터셋 공유](dataset-sharing.md)를
참고한다.
