# 환경 상태

최종 확인일: 2026-08-04

## 설치 항목

- Python 3.12 (검증됨, 최소 3.10)
- 프로젝트 가상환경: `.venv`
- ESP-IDF v5.0.2 (기본 경로 `%USERPROFILE%/esp/esp-idf-v5.0.2`)
- ESP32-S3 도구 체인: GCC 11.2.0
- ESP-CSI 커밋: `740083e5ac0067b8e5ba812d2d08fd94f8ce0348`
- GUI 의존성: PyQt5, PyQtGraph, NumPy, pandas, SciPy

## 확인된 펌웨어

| 펌웨어 | 용도 | 크기 | SHA-256 |
|---|---|---:|---|
| `csi_send.bin` | TX | 685,600바이트 | `9039F1F1F27148FBBD52625E23C59AA771404AA0F7B60A9295E3BC1A2C18A6DA` |
| `console_test.bin` | RX | 825,904바이트 | `174AD1E24FB1A275CE7F877C7F20D00437A7690574AF3764D52BF3D83A5C9B1C` |

두 펌웨어 모두 `esp32s3` 대상으로 빌드하고 실제 보드에 업로드했다.

## 하드웨어

| 역할 | 포트 예시 | USB 인터페이스 |
|---|---|---|
| CSI 송신기 | `COM9` | CH343 UART |
| CSI 수신기 | `COM8` | CH343 UART |

COM 번호와 보드 MAC은 PC·보드마다 다르다. `python -m csi_gateway ports`로
확인한다. 검증된 구성은 ESP32-S3 리비전 0.2, 내장 PSRAM 8MB 보드 2대다.

## 현재 검증 상태

- RX UART 2,000,000 baud 통신 확인
- TX 100Hz ESP-NOW 송신과 RX CSI/Radar 수신 확인
- 채널 1·6·11 런타임 동기 전환 확인
- 전환 후 각 채널에서 Radar 결과 연속 수신 확인
- GUI 현재 채널 표시와 자동 채널 비교 확인
- 다중 공간 프로필 선택·추가·보관 삭제와 보정값 저장·적용 기능 구현
- 수집 세션의 공간 프로필 자동 연결 구현
- 안내형 행동 데이터 수집과 한글 요약 저장 구현
- 모의 낙상과 낙상 유사 행동 라벨 및 안전 확인 추가
- 행동 인식 준비용 세션 특징 추출과 CSV 생성 구현
- 행동당 기존 세션을 기준으로 한 실험용 최근접 행동 예측 구현
- Python 자동 테스트 21개 통과

수집 데이터와 공간 프로필은 저장소에 포함하지 않는다. 각자 자신의 환경에서
링크 확인 → 자동 채널 비교 → 빈 공간 보정 순으로 기준을 새로 잡는다.

실행 명령은 [사용법](usage.md)을 참고한다.
